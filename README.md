- Designed an interactive business dashboard.

## 8. How to Run the Project

Follow these steps to explore and reproduce the analysis:

**Step 1: Clone the Repository**

```bash
git clone https://github.com/your-username/your-repository-name.git
```

**Step 2: Navigate to the Project Folder**

```bash
cd your-repository-name
```

**Step 3: Install Required Python Libraries**

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

**Step 4: Run Python Notebooks**

```bash
jupyter notebook
```

Open the Python notebooks and execute the cells to perform data cleaning and EDA.

**Step 5: Run SQL Queries**

- Create a database in PostgreSQL, MySQL, or SQL Server.
- Import the cleaned dataset.
- Open the SQL query file.
- Execute the queries to reproduce the analysis.

Open the project report and presentation files to review the findings and final insights.
